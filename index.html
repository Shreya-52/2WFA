Why Two-Way Finite Automata matter in computation.

Unlike standard one-way DFAs that consume input sequentially and can never re-read past symbols, a 2WFA can sweep back and forth across a read-only tape with delimiters ⊢ and ⊣.

2★
Directions of Motion
Head moves Left (L), Right (R), or Stays (S) on the read-only tape.

Formal Definition

Mathematical 6-Tuple Definition

A Two-Way Deterministic Finite Automaton (2DFA) is formalized as:

M = (Q, Σ, ⊢, ⊣, δ, q₀, F)

• Q : Finite non-empty set of internal states
• Σ : Input alphabet (not containing ⊢ or ⊣)
• ⊢, ⊣ : Left and right endmarkers defining the tape bounds
• δ : Q × (Σ ∪ {⊢, ⊣}) → Q × {L, R, S}
• q₀ ∈ Q : Initial starting state
• F ⊆ Q : Set of designated accepting states
Decidability & Loop Guard

Loop Detection via Pigeonhole Principle

Because a 2WFA can move left, it is capable of entering infinite loops without terminating. Our engine prevents this using configuration hashing:

Total Configurations = |Q| × (n + 2)

• If the automaton ever visits the exact same state q and tape position pos twice, it must cycle indefinitely.
• By the Pigeonhole Principle, any run exceeding |Q| × (n + 2) steps without halting has entered a loop and is guaranteed to be REJECTED.
